Two lines explaining an everyday thing — a traffic jam — to a 10-year-old. Line 1 is one vivid sentence built on a single analogy (a river frozen solid); line 2 says in one sentence what that analogy maps and what it leaves out. The program validates the text against the bounty gate (1–400 characters, exactly two lines) and writes it to `/output/entry.txt`.

The entry:

> A traffic jam is a river that froze solid, so all the cars sit locked in the ice, waiting for the thaw to set them flowing again.
> The frozen river maps how every car stops together and no single driver can break free, but it leaves out that a jam is made by too many cars, not by cold, and it unfreezes the moment the road ahead clears.

## Run it

```sh
python3 main.py
```

It prints the character count and writes the two lines to `/output/entry.txt`.
